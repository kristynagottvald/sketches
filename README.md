# Sketches

Interactive brand tools by Kristyna Gottvald: type labs, pattern generators, motion systems and small games, each built as a self-contained web page.

**Live site:** https://kristynagottvald.github.io/sketches/

## Projects

| Project | What it does |
| --- | --- |
| [Industry Swapper Plug-in](direct-mail-engine/) | Re-skins one direct mail template for any industry in real time. |
| [Brand Audit Engine](brand-audit-engine/) | Scans assets and flags them as approved, needs review or changes. |
| [Marketing Minesweeper](marketing-mine/) | Minesweeper where every mine reveals a direct mail tip. |
| [Brand Guidelines Mini Site](thread-brand-guidelines/) | Brand guidelines for Thread: voice, logo, type, colour, motion. |
| [Pattern Generator](pattern-generator/) | ASCII pattern engine for brand backgrounds. |
| [Kick Off Type Lab](kickoff-type-lab/) | Groovy, gooey, western lettering with SVG export. |
| [Palette Compositions](palette-compositions/) | Click to cycle palettes through random layouts. |
| [Integratron](integratron/) | A 3D desert dome cycling from day to night, with sound. |
| [Reprise Tiles](reprise-tiles/) | Clickable tiles of Reprise product details. |
| [Banner Template Studio](hero-banner-engine/) | Edit and preview banner templates live. |
| [No-Code Binary Motif](binary-grid/) | A wave of 0s and 1s that follows the mouse. |
| [Temporary Notes](sound-bars/) | Brush across drifting bars to play notes. |
| [Postmark Award Motion Styles](postmark-awards-motion/) | Four award banner styles with PNG export. |
| [Metacognitive Prompt Helper](prompt-machine/) | Rewrites a basic prompt into a metacognitive one. |
| [Mail Stack](mail-stack/) | A ribbon of postcards flowing along a curve. |
| [Brand Colors](motion-character/) | Staggered colour panel wipes. |
| [Postal Fix Animation](postal-fix-animation/) | A motion piece built entirely in code. |
| [Brand Motion System](brand-motion/) | Motion motifs with live palette and type. |
| [Postmark Awards](ribbon-text/) | Text flowing along noise-driven ribbons. |

## Structure

- `index.html` – home page; the project grid is built from `projects.json`.
- `<project>/` – each sketch lives in its own folder with an `index.html` and a thumbnail.
- `clips/` – preview clips shown on the home page.
- `tools/` – helper scripts (see [tools/README.md](tools/README.md)).
