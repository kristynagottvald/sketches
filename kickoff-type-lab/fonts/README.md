# Fonts

Font files are not committed: several are trial, demo or personal-use only. Download them yourself (most are on dafont.com) and put them here with these exact names:

- Bronco.ttf
- CarnevaleeFreakshow.ttf
- Cowboys2.otf
- FonzieMedium.otf
- GomaWestern.ttf
- GomaWestern2.ttf
- Hatten.ttf
- HumaneBlack.otf
- KongGroovy.ttf
- MasaGroovy.ttf
- Monigue.otf
- Muifamoso.ttf
- RetroGroovy.ttf
- SuperGroovy.ttf
- YapariUltra.ttf

Without them the tool falls back to Chango. `index.embedded.html` (fonts as base64) is also left out; regenerate it with `python3 build.py`.
